# Deep CNN Architectures: Build, Train and Compare in PyTorch

## Overview
This project builds five landmark convolutional neural network architectures in **PyTorch** — **LeNet-5, AlexNet, VGG-16, PlacesNet and ResNet-18** — and compares them on the **CIFAR-10** dataset. For each architecture, the full-size network is built first, its layer shapes and parameter counts are printed and verified by hand, and then a scaled-down ("lite") version is trained with exactly the same training code so the results can be compared fairly in one table and one chart.

---

## Features
- Full-size implementations of LeNet-5, AlexNet, VGG-16 and ResNet-18 using `nn.Sequential` and a custom `BasicBlock` module
- A `trace()` helper that pushes a dummy image through a model and prints the output shape and parameter count of every layer
- Manual parameter-count checks using the convolution formula `(K² · C_in + 1) · C_out`, including a comparison against the equivalent dense layer
- **AlexNet:** shows that fully connected layers hold about 94% of the parameters
- **VGG-16:** compares one 5×5 convolution with two stacked 3×3 convolutions (about 28% fewer parameters) and computes receptive fields
- **PlacesNet:** a 365-class AlexNet-style head, a softmax and cross-entropy calculation by hand, and a stage-by-stage receptive field calculation
- **ResNet-18:** proves that a residual block with `F(x) = 0` reduces to `ReLU(x)`, and compares gradient flow in a plain vs. residual 20-layer stack
- Scaled-down "lite" version of each network trained on CIFAR-10 with one shared training function
- Summary table and bar charts comparing test accuracy and parameter count across all five networks

## How to Run

### Step 1: Open the Notebook

```bash
jupyter notebook MCO23378_Lab9.ipynb
```

### Step 2: Run All Cells in Order

CIFAR-10 is downloaded automatically the first time the data-loading cell runs. Only the **first 10,000 training images and the first 2,000 test images** are used, and each network trains for **4 epochs**, to keep the lab short. Because of this, accuracies are far below what full training would reach, so compare the networks with each other rather than with published numbers (chance level is 10%).

Run the cells in order: later experiments reuse the helpers defined in Setup, and every training run adds a row to the `results` dictionary that the final comparison prints.

### Step 3: Compare Results

Each experiment prints the layer-by-layer shapes and parameter counts of the full-size network, then trains its lite version and reports test accuracy after every epoch. The final cells build a summary table and save a comparison chart as `comparison.png`.

## Experiments

| # | Architecture | Key idea demonstrated |
|---|---|---|
| 1 | LeNet-5 | Local receptive fields, weight sharing and subsampling (Tanh + average pooling) |
| 2 | AlexNet | ReLU, dropout in the fully connected layers, large first-layer filter (11×11, stride 4) |
| 3 | VGG-16 | Stacks of small 3×3 convolutions, channel growth block by block, batch norm in the lite version |
| 4 | PlacesNet | Scene classification with a 365-way head; softmax, cross-entropy and receptive field |
| 5 | ResNet-18 | Skip connections `y = F(x) + x`, batch norm after every convolution, global average pooling |

---

## Network Setup

All lite networks share the same data and training code, so only the architecture changes:

- **Dataset:** CIFAR-10, 32×32 colour images, 10 classes (airplane, automobile, bird, cat, deer, dog, frog, horse, ship, truck)
- **Preprocessing:** `ToTensor` followed by normalization to the range [-1, 1]
- **Optimizer:** Adam, learning rate 1e-3
- **Loss:** Cross-entropy
- **Batch size / epochs:** 64 / 4

## Key Takeaway

Deeper and bigger does not automatically mean better under the same training budget. VGG-16-lite has the most parameters but not the best accuracy, while **ResNet-18-lite** reaches the highest test accuracy (0.514) with a moderate parameter count. Its skip connections keep gradients flowing through the network (a gradient norm of about 6 × 10² at layer 1 versus about 3 × 10⁻¹¹ for a plain stack of the same depth), which makes deeper networks much easier to train.
